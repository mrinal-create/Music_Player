# 🎵 Music Player

A simple terminal-based music player built with Node.js.

## 📌 Project Overview

Music Player is a command-line application that allows users to browse and play songs directly from the terminal.

The project is being developed as a learning project to understand:

- Node.js
- File system operations
- Child processes
- Terminal keyboard input
- Music playback
- Git and GitHub
